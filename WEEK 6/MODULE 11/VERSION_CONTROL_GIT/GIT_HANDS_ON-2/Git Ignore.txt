HANDS-ON 2 GIT IGNORE

1. Open Git Repository:

cd GitDemo

git status

2. Create Log File:

type nul > error.log

3. Create Log Folder:

mkdir log

4. Create File Inside Log Folder:

type nul > log\test.txt

5. Check Git Status:

git status

Your branch is up to date with 'origin/master'.

  (use "git add <file>..." to include in what will be committed)

6. Create .gitignore file:

type nul > .gitignore

7. Edit .gitignore file:

* Open GitDemo folder in VisualStudio Code.
* Open .gitignore file and add *.log log/ 

8. Check Status:

git add .gitignore
