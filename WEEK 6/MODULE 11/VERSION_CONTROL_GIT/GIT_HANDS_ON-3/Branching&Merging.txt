HANDS-ON 3 BRANCHING AND MERGING

1. Create a new branch:

git branch GitNewBranch

2. View all branches:

git branch

  GitNewBranch
* master

3. Switch to new branch:

git checkout GitNewBranch

Switched to branch 'GitNewBranch'

4. Verify current branch:

git branch

* GitNewBranch
  master

5. Create new file:

echo This file is created in GitNewBranch > branch.txt

6. Check Status:

git status

On branch GitNewBranch
Untracked files:
  (use "git add <file>..." to include in what will be committed)
        branch.txt

nothing added to commit but untracked files present (use "git add" to track)

7. Add file:

git add branch.txt

8. Commit Changes:

git commit -m "Added branch.txt in GitNewBranch"

9. Switch back to master:

git checkout master

Your branch is up to date with 'origin/master'.

git diff master GitNewBranch

git merge GitNewBranch

git log --oneline --graph --decorate

13. Delete branch:

git branch -d GitNewBranch

Deleted branch GitNewBranch (was 3bc3f6d).

14. Verify Branch:

git branch

* master

15. Push the Changes to GitHub:

git push origin master
